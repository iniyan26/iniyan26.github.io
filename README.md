# Iniyan A — Portfolio Website

A responsive single-page portfolio for PCB design and embedded hardware projects, built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `iniyan26.github.io` (or use another repository name).
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing

- Check the resume in `assets/resume.pdf` and replace it if you have a newer final PDF.
- Replace project links that currently point to your GitHub profile with each project's individual repository when you upload them.
- Confirm your LinkedIn URL and all project descriptions are accurate.

The site intentionally describes the BMS project and Altium Designer Essentials course as in progress, and does not claim the ongoing training is a completed certification.
