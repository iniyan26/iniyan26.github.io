# Iniyan A — PCB Design Portfolio

This is the updated, self-contained portfolio website. The page styling is included in `index.html`; no separate CSS or JavaScript files are required.

## Publish with GitHub Pages

1. Download and extract this ZIP.
2. Open the `iniyan26.github.io` repository on GitHub.
3. Upload `index.html` and the `assets` folder directly into the repository root (not inside another `iniyan-portfolio` folder).
4. Commit the changes. If prompted to replace `index.html`, replace the old version.
5. Keep GitHub Pages set to branch `main` and folder `/(root)`.
6. After deployment, visit https://iniyan26.github.io/ and refresh.

The `assets/resume.pdf` file is used by the View Resume link, so upload the `assets` folder as well.
