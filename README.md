# Iniyan A — Portfolio Website

A responsive single-page portfolio for PCB design and embedded hardware projects, built with HTML, CSS and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository named `iniyan26.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and this README.
3. Open **Settings → Pages**, choose **Deploy from a branch**, then `main` and `/ (root)`, and save.
4. Wait a minute or two, then open https://iniyan26.github.io

## Before publishing

- Make sure the Google Drive resume link is set to "Anyone with the link can view".
- When the BMS PCB repository is on GitHub, replace its profile link with the repository link.
